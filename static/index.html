Panduan 5 langkah mudah menyusun pipeline Computer Vision di AFI Vision Builder:
  1. 1. Pilih Sumber Input

    Tarik node Input ke kanvas. Pilih jenis input: Kamera Laptop/Webcam, CCTV RTSP/HTTP, Video MP4 Lokal, atau Streaming YouTube langsung via URL.

  2. 2. Hubungkan Model Deteksi AI

    Sambungkan kabel dari port frame node Input ke port frame node Detector (YOLOv8, YOLO-World Zero-Shot, atau Roboflow Universe).

  3. 3. Tambahkan Tracker Objek

    Hubungkan port detections dari detektor ke node Tracker (ByteTrack) untuk pelacakan identitas objek yang stabil di setiap frame.

  4. 4. Tambahkan Analisis Spasial & Aturan

    Gunakan node analitik seperti Zone Activity Timer (meja/workshop), Distance Measurement (jarak fisik), Overlap Analysis (APD), atau Velocity Calculator.

  5. 5. Tampilkan Visualisasi & Jalankan

    Sambungkan output ke node Overlay Annotate dan Preview. Tekan tombol Run di bagian atas untuk mulai memproses secara real-time!
